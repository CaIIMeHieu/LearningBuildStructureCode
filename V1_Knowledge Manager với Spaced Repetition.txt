1. Register / Login (JWT hoặc Google OAuth2)
        ↓
2. Tạo Deck — "chủ đề học" (vd: "ASP.NET Core", "Tiếng Nhật N3")
        ↓
3. Thêm Card vào Deck — mỗi Card là 1 đơn vị kiến thức
   Card có 2 dạng:
   - Q&A: Question + Answer
   - Note: ghi chú tự do (AI sẽ đọc và gợi ý câu hỏi)
        ↓
4. AI đọc ghi chú → gợi ý câu hỏi → user approve → thành Card
        ↓
5. Mỗi ngày: system hiển thị các Card "đến hạn ôn" (SM-2 algorithm quyết định)
        ↓
6. User review từng Card → đánh giá: Again / Hard / Good / Easy
   → SM-2 tính lịch review tiếp theo (1 ngày / 3 ngày / 1 tuần / v.v.)
        ↓
7. Streak tracking: review đủ mỗi ngày → streak tăng
   Reminder email: hôm nay chưa review → 9h tối nhận email nhắc


--------------------------------- Thuật toán SuperMemo ------------------------------------
SM-2 algorithm:
    Ý tưởng : Thứ người dùng nhớ tốt thì ôn thưa hơn, thứ nhớ kém thì ôn dày hơn
    3 chỉ số :
        1. Interval (I): khoảng thời gian giữa các lần review
            Card mới: Interval = 1 (review ngày mai)
            Lần 2 đúng: Interval = 6
            Lần 3+ đúng: Interval = Interval × EaseFactor
        2. Ease Factor (EF): độ dễ nhớ của Card, ảnh hưởng đến tốc độ tăng Interval
            Mặc định: 2.5
            User đánh giá Easy → EaseFactor tăng → interval sau dài hơn
            User đánh giá Hard/Again → EaseFactor giảm → interval sau ngắn hơn
            Floor: 1.3 (không giảm dưới đây)
        3. Repetition (R): số lần đã review
            User đánh giá Again → Repetitions reset về 0, Interval reset về 1
            User đánh giá đúng → Repetitions + 1
